## Method notes

- Bar direction: sign(close - prev_close). Doji bars (Δ=0) terminate runs, do not start new ones.
- Run magnitude = |close[end] − open[start]|, normalized by ATR(14, Wilder) sampled at the bar **before** run start.
- Causal entry: open of (run_end_idx + 2). Waits for the reversal-confirming bar to close. Deployable.
- Look-ahead entry: open of (run_end_idx + 1). 1-bar look-ahead, reported only as a sanity check.
- Forward returns signed so positive = mean-reversion paid (short after up-runs, long after down-runs).
- Runs spanning a session boundary (RTH ↔ ETH) are dropped.
- Endpoints whose longest-horizon (30-bar) trade window crosses a session boundary are dropped uniformly across all horizons (sample set identical at h=1 and h=30 within a stratum).
- **Roll filter**: bars within +/-3 CT days of each quarterly roll (3rd Thu Mar/Jun/Sep/Dec) are dropped. Empirically, 1m bars at ~19:01 CT on roll-day eve show 200-235 pt gaps (catalog continuous-contract rolls). Without this filter, those gap bars dominate the high-magnitude mean-reversion buckets.
- Cells with n < 100 samples are flagged unreliable in heatmaps.

## Caveats

- No transaction costs applied. Net of ~1 tick of friction on NQ ($5/contract round-trip), edges below ~0.05 ATR are unlikely tradeable.
- Single calendar year (2025). Out-of-sample validation needed before trusting any cell.
- Bucket boundaries are arbitrary. Re-run with finer buckets to expose sub-structure.
- Doji bars (close==prev_close) reset the run counter. Rare on 1m NQ but non-zero in illiquid hours.
- Roll filter is a +/-3 day calendar buffer, not a tick-level surgical cut. Conservative; trades sample size for safety.
