# SL × BE Grid at 1s Precision

## Method

- Triggers: 1m Goldilocks bars (V_A baseline)
- Execution: 1s bars (BE arming + BE stop + cat stop + target + EOD)
- BE stop offset: +1 tick (favorable side; covers commission)
- BE stop delay: 1 bar (NT-realistic; stop placed AFTER arm bar)
- Skip-while-open at 1s precision
- EOD flat at 16:00 CT
- Commission: 0.25 pt round trip
- NQ multiplier: $20.0/pt

BE_PTS = 0 means no BE arming (only cat SL + target + EOD).
SL = no-cat means no catastrophic stop (only BE + target + EOD).
