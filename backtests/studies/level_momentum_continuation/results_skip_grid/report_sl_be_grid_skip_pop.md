# SL × BE Grid on Skip-While-Open Population

## Method

Fixed population: takes the trades that survived skip-while-open (BE=2.5 + original 'one prior in seq' stops). For each (SL, BE) combo, re-simulates only the EXIT logic on those trade indices.

SL grid: ['ORIG', 5.0, 7.5, 10.0, 12.5, 15.0, 20.0, 25.0, 30.0]
BE grid: [0.0, 2.5, 5.0, 7.5, 10.0]
Commission: 0.25 pt. NQ multiplier: $20.0/pt.

Caveat: 'fixed population' means the trade SET was selected by the original BE=2.5 + level-structure stops. The SL / BE grid below tests alternative exits on those specific trade indices. The actual deployable population would shift if SL/BE changed (Option B), but this Option A view is faster and answers 'best exit for these trades'.
